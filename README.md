# Chalant-Bot-21

a super chill slack bot running 24/7 on a cloud server that drops facts, doggos, hype, and NASA stuff directly into your channel.

## Features

- '/chalant-bot-21-ping' - Checks bot latency
- '/chalant-bot-21-namaste' - Sends a friendly greeting
- '/chalant-bot-21-hype' - Get a random hype compliment
- '/chalant-bot-21-catfact' - Fetch random cat facts
- '/chalant-bot-21-dog' - Get cute dog pictures
- '/chalant-bot-21-activity' - Get random activity ideas
- '/chalant-bot-21-nasa' - Daily NASA APOD and details
- '/chalant-bot-21-help' - View all commands

## Built With 
- **Node.js** & **Slack Bolt SDK** (Socket Mode)
- **Axios** (for fetching APIs)
- **Systemd** (to keep it running 24/7 on Linux)
